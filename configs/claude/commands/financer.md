description: Run the financer subagents — screen the core ETF allocation and Taiwan / US candidate stocks on a fixed fundamentals framework, assess whether the Taiwan / US index level is earnings-backed, and save a dated report under ~/financer/reports/
---
Dispatch the `financer` subagent (Agent tool, `subagent_type: "financer"`, model opus) to produce a personal stock research report. US-listed stocks go to its twin `financer-us` instead (see **US stocks** below).

- **Split the watchlist by market first.** Taiwan: 4–6 digit codes, Chinese names of Taiwan companies, and English or ADR names of Taiwan companies (`TSMC`, `UMC`, `ASX` → `financer` maps them to the Taiwan listing). US: everything else that names a company listed in the US — tickers (`NVDA`, `BRK.B`) and company names in any language (`intel`, `輝達`), which you turn into tickers yourself. Foreign non-Taiwan ADRs (`SKHY`, `BABA`) go to the US side, which reports them as unsupported. When a name could be either, ask rather than guess.
- Pass the Taiwan part of $ARGUMENTS through verbatim as the watchlist / focus: codes, Chinese names, English names and ADR names (e.g. `TSMC`) are all fine — the subagent resolves them to Taiwan codes itself. If $ARGUMENTS is empty, tell the subagent to use the core allocation in `~/financer/ref/core-allocation.md` and pick its own 3+ candidates.
- Scope keyword (default `all`, pick one): `ETF` → only 核心配置檢視; `股票` / `stock` → only 潛力股評估 / 除權息 / 法人與總經; `法人` → only the institutional-flow section; `預警` / `--warn` → signal-timing review; `大盤` / `market` → index real-vs-hollow assessment, optionally narrowed with `台股`/`tw` or `美股`/`us` (no stock codes); `all` → ETF + stocks. Every Chinese keyword has an English alias (`etf`, `stock`, `chips`, `warning`, `market`). 「與上次比較」「免責」always render. Combinable with the watchlist and flags (e.g. `2330 2454 股票`, `ETF -S`).
- **`--movers [N]`** (alias `漲幅 [N]`, N = minimum % change, default 9): screen the day's big movers *before* dispatching. Run `python3 -I ~/financer/scripts/movers.py --threshold N` yourself (Bash; add `--date YYYYMMDD` if the user names a day). It prints a markdown screen and, on its last line, the JSON path.
  - Exit 2 = no closing data (holiday, or before ~14:30): say so and stop. Zero picks: show the screen and stop — no dispatch, no report.
  - Otherwise show the user the screen, then dispatch with scope `stock` and the picks' codes **in the script's order** (the subagent deep-evaluates the first 4 and snapshots the rest). In the prompt add a 呼叫端背景 line: "`/financer --movers N` 預篩，結果見 <JSON path>（Read 它取門檻與被刷掉的名單）；預篩數字只用來挑標的，報告數字請自行查證引用".
  - `--movers` implies `stock`: refuse it with another scope or with explicit codes (one sentence on the right form), without running anything. `-S`, `--no-chart` and a window still pass through.
- **Statement prefetch** (any scope that deep-evaluates stocks — `stock`, `all`, `--movers` — and only when stocks are named or picked): before dispatching, run `python3 -I ~/financer/scripts/prefetch.py <each code or name>` yourself (Bash). It writes one FinMind statements file per stock and prints a table plus, on its last line, the directory. Exit 3 means some names were skipped (ETFs, unknown or ambiguous names); dispatch anyway. Add a 呼叫端背景 line: "財報預抓檔在 <directory>/<代號>.md（Read 它，規則見鐵則 3「財報預抓檔」）；未預抓：<skipped names or 無>". Skip this step when no stocks are named (the subagent picks its own) or the scope is `ETF`, `法人`, `預警` or `大盤`.
- Recognised flags: `--sources` (aliases `-S`, `附來源`) — appends 「附錄 A、資料來源清單」with each figure's full URL + access date (inline site+date citations are always present); `--no-chart`; `--consensus` (aliases `共識`, `目標價`) — adds 「D. 市場預期對照」, quoting recent named-broker ratings and target prices without rating them (stock scopes only); a window such as `近5日` / `5d`, `本月` / `mtd`, or `20250101-today` for the institutional section.
- **`--plain`** (aliases `plain`, `白話`): after relaying the report, append a 「白話解說」 that you write yourself from the saved file — the subagent never sees this flag, so strip it from what you pass through. Combinable with any scope, flag or `--movers`.
  - Use only figures already in the report: no new lookups, no new numbers, no buy/sell, target price or entry/exit wording.
  - Explain jargon (ROE, PER, D/E, 背離, 快照) with everyday analogies, reusing the wording and the 飲料店 example of `~/financer/docs/reading-guide.md` so explanations stay consistent across reports (Read it first). Per deep-evaluated stock: what the business is, the rating and why, the top risks; per snapshot: why it was not rated. With 2+ stocks, end with a short comparison table.
  - Without codes, a scope or `--movers`, `--plain` explains an existing report instead of dispatching: a file name or path under `~/financer/reports/`, or the newest `INDEX.md` row when none is given. Read it and explain it; no subagent, no new report.
- **US stocks** (`financer-us`): scope is always stock. A US ticker with an explicit `ETF`, `法人`, `預警`, `大盤` or `all`, or with `--movers`, gets one sentence explaining that US stocks only take the stock scope (and that `大盤 us` takes no tickers), without running anything.
  - Before dispatching, run `python3 -I ~/financer/scripts/prefetch_us.py <tickers>` yourself (Bash). It writes one SEC XBRL / Yahoo price / FINRA short-interest file per ticker and prints a table plus, on its last line, the directory. Exit 3 means some tickers were skipped (unknown ticker, or a foreign 20-F filer); dispatch anyway.
  - Dispatch `subagent_type: "financer-us"` (model opus) with the tickers and the flags `-S`, `--no-chart`, `--consensus` (strip `--plain`, a window and `stock`), plus a 呼叫端背景 line: "美股財報預抓檔在 <directory>/<代號>.md（Read 它，規則見鐵則 3）；未預抓：<skipped tickers and the script's reason, or 無>".
  - A mixed watchlist dispatches both subagents (in parallel, one message) and relays both reports, each with its own saved path. `--plain` explains each report separately.
- The subagent needs live web data (WebSearch / WebFetch). It must cite a source + date for every figure and mark anything it cannot find as「資料未提供」— never fabricate numbers. Biotech / pre-profit stocks are excluded, not force-fitted.
- **Do not name the output file.** The subagent names it by its own convention (scope + codes), saves it under `~/financer/reports/`, and adds a row to `~/financer/reports/INDEX.md`.
- Relay the report back verbatim, with the saved path; do not add buy/sell recommendations of your own.
